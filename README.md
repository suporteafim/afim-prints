# afim-prints
Robôs que tiram prints do Afim (Guaíra-SP) em simuladores oficiais, rodando no GitHub Actions.
- iOS: simulador da Apple (Xcode) em runner macOS. Passo a passo "Adicionar à Tela de Início" no Safari.
- Android: emulador AOSP em runner Ubuntu (KVM). Instala o APK e abre o app.
Prints saem como artifacts de cada execução.
